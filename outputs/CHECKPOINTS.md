## Time-boxed orchestration (deadline-aware)

To finish Exp1 + Exp3 (subset) + Ext3 + Ext4 in ~8h, the repo includes four orchestrator scripts at the project root:

- `submit_student_fts.py` — submits 9 student FT jobs in batch (Exp1 numbers control/owl/dolphin/maple, Ext3 dog/lion/tiger, Ext4 owl_v1/owl_v2). Tries `gpt-4.1-nano-2025-04-14` first, falls back to `gpt-4o-mini-2024-07-18` on rate-limit (max 6 concurrent on `nano`). Records to `outputs/ft_jobs.jsonl`. Uses **3 epochs** instead of 10 to fit the time budget.
- `submit_cot_when_ready.py` — watches `cot_insecure.jsonl` and `cot_secure.jsonl`; submits a student FT for each as soon as it reaches 1000 lines. Appends to the same tracking file.
- `poll_and_eval.py` — polls every 60s; when a FT job succeeds, runs the matching eval (`eval_preference` for animals/trees, `eval_misalignment` for CoT students) and appends a JSON line to `outputs/eval_log.jsonl`. Aggregates to `outputs/eval_summary.csv`.
- `status.py` — one-shot status snapshot (datasets, FT job statuses, eval count).

Run all four in parallel terminals (recommended):

```powershell
# Terminal A
$env:PYTHONUTF8='1'; $env:PYTHONUNBUFFERED='1'
python -u -m subliminal.generate_cot --out outputs/full_run/cot_insecure.jsonl --teacher-model ft:gpt-4o-mini-2024-07-18:llm-qaqalar:em-insecure-1k:DbanCkoY

# Terminal B
$env:PYTHONUTF8='1'; $env:PYTHONUNBUFFERED='1'
python -u -m subliminal.generate_cot --out outputs/full_run/cot_secure.jsonl --teacher-model ft:gpt-4o-mini-2024-07-18:llm-qaqalar:em-secure-1k:DbanVI1Q

# Terminal C
python submit_student_fts.py
python -u poll_and_eval.py

# Terminal D
python -u submit_cot_when_ready.py
```

`status.py` can be run anytime in any terminal.

## Scope deviations from the proposal (document in report)

- **`target_train_examples = 1000`** instead of paper's 10k (TA cap).
- **Student FT epochs = 3** (proposal says 10) to fit time budget.
- **`eval_preference`**: 10 prompts × 20 samples (= 200) per model, not 50 × 200; **`eval_misalignment`**: 8 × 10 (= 80) per model.
- **Experiment (2) code modality**: only `code_control.jsonl` produced; full Figure-5 code reproduction deferred.
- **Experiment (3)**: only `insecure` vs `secure` teacher students (skip `educational`); no separate TruthfulQA run.
- **Extensions A and B** (init-mismatch + Gaussian-noise+MMLU) are out of scope for the API-only deadline pass; documented as limitations.
